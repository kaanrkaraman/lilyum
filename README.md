# Lilyum

A Dynamic Island for the Mac notch: music, your day, a file shelf, a timer, and quick alerts for volume, brightness, Focus, AirDrop, notifications and calls.

## Download

Get the latest DMG from [Releases](https://github.com/kaanrkaraman/lilyum/releases/latest). Lilyum updates itself through Sparkle.

## Requirements

- A notched MacBook (14-inch or 16-inch MacBook Pro, or a notched MacBook Air)
- macOS 15 or later

This repository holds releases only.
